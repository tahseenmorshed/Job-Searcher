## Relevance guide
Judge relevance by what the person spends their time doing, not by the job title
or by how closely the tech stack matches mine. A backend role in Go is still core.

- core: writing and maintaining code is the main job: backend, full-stack, Java,
  C++/systems, API and integration development. This includes building a company's own
  internal tools or internal platform in general-purpose languages, even when the title
  says "platform".

- adjacent: technical roles close to software engineering, with or without much coding:
  - DevOps / platform / cloud engineering, data engineering, test automation / QA engineering,
    AI/ML engineering, embedded software.
  - Development on a vendor's product: Salesforce, ServiceNow, Dynamics 365, SAP (ABAP) and similar.
  - Administration or configuration of a software platform (e.g. Salesforce Administrator,
    LIMS administrator), including low-code tools.
  - Data analyst and reporting / BI roles (e.g. Power BI developer).
  - Support analyst roles (application, production, systems support), even with no development work.

- not_relevant: IT helpdesk / desktop support, network or systems administration,
  project / programme management, business analysis, sales or pre-sales, finance,
  hardware / electrical engineering.

If torn between adjacent and not_relevant, choose adjacent.
